# Codex Pets

A collection of custom Codex-compatible animated pets.

## Xuemei Study Buddy v2

Xuemei is a Codex v2 animated desktop pet with nine standard animation rows and sixteen look directions.

### Repository layout

```text
pets/
└── xuemei-study-buddy-v2/
    ├── pet.json
    └── spritesheet.webp
```

### Install

1. Download the package from the [v2.0.0 release](https://github.com/miya-as/codex-pets/releases/tag/v2.0.0).
2. Extract `xuemei-study-buddy-v2` into `~/.codex/pets/`.
3. Open the Pets settings, refresh custom pets, and select **雪美学习伙伴 v2**.
